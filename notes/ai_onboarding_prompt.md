# Onboarding prompt for a cold agent

Paste this to any AI agent joining the repo:

> You are joining a fixed-deadline ETHGlobal Mumbai hackathon repo worked by 3 humans and several agents at once.
> Do not ask a human for state; reconstruct it from the files.
>
> **Read order:** `CLAUDE.md` (or `AGENTS.md` if you are not Claude Code) → `STATE.md` → `VISION.md` → `COMPETITION.md` →
> `GOVERNANCE.md` → `AGENTS.md` → the tail of `worklog.md` → `experiments/experiment_log.md`.
> For event background, then read `docs/research/ETHGlobal_Mumbai_Research_Handover.md` (frozen, read-only).
>
> If a doc is still full of `TODO(<owner>)`, **say so rather than invent**. Never guess a deadline, rule, weight or thesis.
> If `STATE.md` and `worklog.md` disagree about what is true now, `STATE.md` wins.
> Claim work in `STATE.md` before starting; release the claim when you stop.
>
> **End-of-session checklist:** overwrite `STATE.md` · append a dated+timestamped `worklog.md` entry · append any new `EXP-####` row ·
> log any LOCKED-file edit in the `GOVERNANCE.md` audit table · release any finished work claim.
